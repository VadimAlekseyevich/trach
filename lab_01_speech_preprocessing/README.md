# Лабораторная работа № 1

**Подготовка данных и извлечение акустических признаков речи.**

Основной файл: `prepare_dataset.py`. Код соответствует функции `preprocess_dataset` в приложении методических указаний (страница 49).

## Запуск в PyCharm

1. Откройте папку `lab_01_speech_preprocessing` в проекте.
2. Убедитесь, что установлена библиотека `librosa` (при необходимости установите зависимости из `requirements.txt`).
3. Нажмите правой кнопкой на `prepare_dataset.py` → **Run 'prepare_dataset'**.
4. После выполнения появится файл `data.json` рядом с программой.

В папке `dataset` находятся три папки: `bed`, `cat`, `happy`.

Программа читает записи, оставляет первую секунду (22050 отсчётов), пропускает записи короче секунды и вычисляет MFCC (`num_mfcc=21`, `n_fft=2048`, `hop_length=512`). Результат сохраняется в `data.json` с полями `mapping`, `labels`, `MFCCs`, `files`.

**Примечание:** в теоретической части методички встречается число 13 MFCC, но в готовом листинге на странице 49 указано `num_mfcc=21`. Здесь оставлено 21, как в листинге.

По шагу 3 первой лабораторной для последующей лабораторной № 3 следует **вручную** отложить несколько десятков WAV-файлов в отдельную папку и убрать их из `dataset`. Отдельной программы для этого в методичке нет.
