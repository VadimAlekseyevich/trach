# Лабораторная работа № 1 — подготовка аудиоданных и MFCC

Код по методическим указаниям **«Распознавание речевых сигналов с помощью искусственной нейронной сети»**, лабораторная работа № 1 (стр. 5–21), листинг `preprocess_dataset` (стр. 49).

Задача: извлечь мел-частотные кепстральные коэффициенты (MFCC) из звуковых записей и сохранить `data.json` для следующей лабораторной работы (обучение CNN).

## 1. Размещение данных

Набор данных, выданный преподавателем, нужно самостоятельно скопировать в папку `dataset`. В Git аудиофайлы не загружены.

```text
lab_01_speech_preprocessing/
├── prepare_dataset.py
├── reserve_test_samples.py
├── requirements.txt
├── dataset/                 # скопировать самостоятельно
│   ├── bed/
│   │   └── *.wav
│   ├── cat/
│   │   └── *.wav
│   └── happy/
│       └── *.wav
└── data.json                # появится после запуска
```

Классы нумеруются **в алфавитном порядке**: `bed → 0`, `cat → 1`, `happy → 2`. Код допускает и другие названия папок: фактический порядок записывается в `mapping`.

## 2. Установка и запуск

Нужен **Python 3.10+**. Из терминала в папке `lab_01_speech_preprocessing`:

```bash
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python prepare_dataset.py
```

Если датасет находится в другом месте:

```bash
python prepare_dataset.py --dataset "C:/path/to/dataset" --output data.json
```

## 3. Что делает программа

1. Читает `.wav` из подпапок датасета и присваивает номер каждому классу.
2. С помощью `librosa.load(..., sr=22050)` преобразует запись в моно и приводит частоту дискретизации к **22 050 Гц**.
3. Пропускает записи короче **1 секунды** (включая пустые) и обрезает более длинные до **22 050 отсчётов**.
4. Вычисляет MFCC с параметрами **`n_fft=2048`**, **`hop_length=512`**, **`n_mfcc=21`**.
5. Создаёт `data.json` с полями `mapping`, `labels`, `MFCCs`, `files`; MFCC представлены вложенным списком `[временной_кадр][коэффициент]`.

Параметры можно изменить, например получить **13 MFCC**, как указано в теоретическом описании лабораторной:

```bash
python prepare_dataset.py --num-mfcc 13
```

**Замечание по методичке:** на стр. 7 и 9 упомянуто 13 коэффициентов, однако код в приложении на стр. 49 использует `num_mfcc=21`. По умолчанию здесь выставлено **21 — как в листинге**. Для следующей лабораторной используйте одинаковое количество коэффициентов и при обучении, и при распознавании.

В сравнении с дословным листингом исправлены проверки путей и обход каталогов, добавлена сортировка имён для стабильных меток, фильтрация `.wav` и обработка некорректных записей. **Формат результата сохранён как в методичке.**

## 4. Файлы для лабораторной № 3 (необязательно, но рекомендуется сделать до подготовки JSON)

В шаге 3 методички рекомендуется вынести несколько десятков записей из исходного датасета для независимого финального теста. Для этого предусмотрен дополнительный скрипт:

```bash
# Сначала только показать, что будет перемещено:
python reserve_test_samples.py --per-class 10 --dry-run

# Затем перенести по 10 WAV из каждого класса (30 файлов):
python reserve_test_samples.py --per-class 10

# Только ПОСЛЕ этого подготовить обучающий датасет:
python prepare_dataset.py
```

Выбранные файлы переместятся в `test_audio/bed/`, `test_audio/cat/`, `test_audio/happy/` и не попадут в `data.json`. Можно выбрать другое количество с помощью `--per-class` и фиксировать случайный выбор через `--seed`. Скрипт ничего не перемещает сам по себе — только при отдельном запуске без `--dry-run`.
