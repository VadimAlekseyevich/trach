# Лабораторная работа № 2 — экспертная система «Туристическое агентство»

**Дисциплина:** Проектирование интеллектуальных информационных систем  
**Группа:** 344  
**Вариант:** 2 — подбор страны/туристического направления по предпочтениям туриста.  
**Язык:** SWI-Prolog (файлы `.pl`).

## Что реализовано

- 8 обязательных вопросов: климат, вид отдыха, бюджет, сезон, длительность, транспорт, проживание, компания.
- 18 известных направлений (факты `destination/3`).
- Рекурсивное правило `compatible/2` последовательно проверяет все восемь ответов; `recommend/3` выводит подходящее направление.
- Если совпадений нет, программа честно сообщает о недостатке знаний.
- Вопрос повторяется при вводе некорректного номера; конец ввода обрабатывается без зависания.
- Русскоязычный диалог. Внешние Python-пакеты не нужны.

> Направления и уровни бюджета — **учебные примеры**, а не проверенные предложения туроператоров; программа не проверяет актуальные визы, стоимость, маршруты или безопасность поездки.

## Установка и запуск на Windows (CMD)

Нужен Windows 10/11 с `winget` (App Installer), Интернетом, встроенными `curl.exe` и `cmd`. Для простого запуска **Git и Python не требуются**.

Вставьте **одну строку** в CMD (она установит SWI-Prolog, скачает один файл программы с GitHub и запустит опрос):

```cmd
winget install --id SWI-Prolog.SWI-Prolog --exact --accept-package-agreements --accept-source-agreements && cd /d "%USERPROFILE%" && curl.exe -fL -o lab2_tourism.pl https://raw.githubusercontent.com/VadimAlekseyevich/trach/main/lab_02_tourism_expert_system/main.pl && chcp 65001 >nul && "%ProgramFiles%\swipl\bin\swipl.exe" -q -s lab2_tourism.pl -g main -t halt
```

Если SWI-Prolog уже стоит, начните со второго фрагмента (`cd /d ...`). При установке программа может запросить подтверждение прав. Если ваш установщик выбрал нестандартный каталог, замените `%ProgramFiles%\swipl\bin\swipl.exe` фактическим путем к `swipl.exe`.

## Запуск из папки проекта

Если репозиторий уже скачан, откройте CMD в `lab_02_tourism_expert_system` и выполните:

```cmd
chcp 65001
"%ProgramFiles%\swipl\bin\swipl.exe" -q -s main.pl -g main -t halt
```

После запуска вводите **номер варианта ответа**, нажимая Enter. Всего 8 вопросов. Появится рекомендуемая страна/место или сообщение о неизвестном решении.

## Проверка работы

В папке `examples/` лежат файлы с готовыми ответами: `known_turkey.txt`, `known_japan.txt`, `unknown.txt`. Они нужны для воспроизведения двух успешных и одного неизвестного диалогов (в будущем — для отчета).

```cmd
"%ProgramFiles%\swipl\bin\swipl.exe" -q -s main.pl -g main -t halt < examples\known_turkey.txt
"%ProgramFiles%\swipl\bin\swipl.exe" -q -s main.pl -g main -t halt < examples\known_japan.txt
"%ProgramFiles%\swipl\bin\swipl.exe" -q -s main.pl -g main -t halt < examples\unknown.txt
```

Автоматические тесты программы:

```cmd
"%ProgramFiles%\swipl\bin\swipl.exe" -q -s tests.pl -g run_tests -t halt
```

## Как работает логический вывод

`recommend(Answers, Name, Description)` перебирает факты `destination/3` с помощью механизма поиска решений Пролога. Для каждого направления `compatible/2` рекурсивно проверяет: найден ли ответ по очередному вопросу среди допустимых значений. При неудаче происходит возврат к следующему направлению. Система предлагает **первое полностью подходящее** направление в порядке базы знаний. Если такого нет, выводится сообщение о неосведомленности.

Чтобы расширить базу знаний, добавьте новый факт `destination/3`, указав допустимые значения для всех 8 параметров из `question_keys/1`.
